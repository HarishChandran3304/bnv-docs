Need help? Use [GitHub Issues](https://github.com/HarishChandran3304/better-env/issues) for bug reports, feature requests, and support questions.

## Reporting Bugs

Before reporting, check [existing issues](https://github.com/HarishChandran3304/better-env/issues) and ensure you're on the latest version.

Include:
- Clear description and steps to reproduce
- Expected vs actual behavior
- OS, better-env version (`bnv --version`), and shell type
- Error messages or logs

## Requesting Features

We'd love to hear what you'd like to see in better-env.
Please open an issue on [GitHub](https://github.com/HarishChandran3304/better-env/issues) with your request.

Include:
- Use case and problem you're solving
- Proposed solution
- Any alternatives considered
- Any relevant documentation or examples

## Asking for Help

If you're having trouble using better-env, please open an issue on [GitHub](https://github.com/HarishChandran3304/better-env/issues) with your question.

Include:
- What you're trying to do
- What you've tried
- Your environment details
- Any error messages
